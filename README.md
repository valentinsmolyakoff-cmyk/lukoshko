# 🦔 Лукошко — как открыть игру по ссылке

Игра уже **запущена и доступна онлайн** (живое превью в этом чате). Всё, что ниже, — про то, как
открыть её где угодно: на телефоне ребёнка, на планшете, на компьютере, без интернета и с иконкой
на домашнем экране.

---

## 1. Прямо сейчас: три способа открыть

| Способ | Что делать | Когда нужен |
|---|---|---|
| **Живое превью** | Открыть превью в этом чате (порт `8000`) | Быстро поиграть и показать |
| **Локально у себя** | Скачать папку `lukoshko` и запустить `python3 serve.py` → открыть `http://localhost:8000` | Без интернета, дома |
| **Двойной клик по `index.html`** | Игра тоже работает, но без установки на телефон и без офлайн-кеша | Просто посмотреть |

> Почему не всегда `file://`: для установки на домашний экран (PWA) и офлайн-режима браузеру нужен
> `http://` или `https://`. Локальный `serve.py` это даёт; в интернете — любой бесплатный хостинг.

## 2. Постоянный публичный адрес (10 минут, бесплатно)

Нужен только статический хостинг — игра это 8 файлов, без сервера и базы данных.

### Вариант А. Netlify Drop — самый быстрый (без регистрации для пробы)
1. Зайти на <https://app.netlify.com/drop>.
2. Перетащить **папку `lukoshko`** целиком в окно.
3. Через ~10 секунд появится ссылка вида `https://lukoshko-xyz.netlify.app` — её можно отправлять бабушке.
4. Бесплатный аккаунт закрепит сайт навсегда и позволит менять имя.

### Вариант Б. GitHub Pages — бесплатно и навсегда
```bash
# в папке lukoshko
git init
git add .
git commit -m "Лукошко: игра для детей 5+"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/lukoshko.git
git push -u origin main
```
Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через минуту адрес: `https://<ваш-логин>.github.io/lukoshko/`.

### Вариант В. Cloudflare Pages / Vercel
- Cloudflare Pages: **Create project → Upload assets** → загрузить папку → домен `*.pages.dev`.
- Vercel: `npx vercel` в папке проекта (или drag-and-drop в панели) → домен `*.vercel.app`.

### Вариант Г. Свой домен
На любом из хостингов выше: **Domain settings → Add custom domain** → прописать CNAME у регистратора.
Итог: `https://игра-лукошко.by` — HTTPS-сертификат выдаётся автоматически.

> ⚠️ После любой правки уровней увеличивайте версию кеша в `sw.js` (`const CACHE = 'lukoshko-v2'`),
> иначе у тех, кто уже играл, останется старая версия из офлайн-кеша.

## 2а. Деплой в один шаг (добавлено)

В папке уже лежит всё для публикации:

| Файл | Для чего |
|---|---|
| `lukoshko-site.zip` (88 КБ) | Готовый архив: перетащить на <https://app.netlify.com/drop> → сайт за ~20 секунд |
| `deploy.sh` | `./deploy.sh zip` / `netlify` / `vercel` / `gh <логин> <репо>` — публикация одной командой |
| `netlify.toml`, `_headers` | Заголовки безопасности (CSP, no-sniff), кеш: страница не кешируется, картинки — на неделю |
| `vercel.json` | То же для Vercel |
| `.github/workflows/pages.yml` | Авто-деплой на GitHub Pages при каждом push в `main` |
| `404.html` | Красивая страница «Ёжик не нашёл страничку» с кнопкой возврата в игру |

**Примеры:**
```bash
export NETLIFY_AUTH_TOKEN=...   # User settings → Applications
./deploy.sh netlify новая       # создаст сайт и опубликует

export VERCEL_TOKEN=...
./deploy.sh vercel

./deploy.sh gh мой-логин lukoshko   # затем Settings → Pages → Source: GitHub Actions
```

Токены и доступы я не запрашиваю и не храню — публикация идёт либо с вашей машины,
либо через подключённый сервис (например, Vercel), если вы его разрешите в чате.

## 3. Установка на телефон и планшет

**Android (Chrome):** открыть ссылку → меню «⋮» → **Установить приложение** (или «Добавить на главный экран»).
Появится иконка ёжика, игра откроется на весь экран без адресной строки.

**iPhone / iPad (Safari):** открыть ссылку → «Поделиться» → **На экран «Домой»**.

**Компьютер (Chrome/Edge):** значок «Установить» в адресной строке.

После установки игра **работает без интернета** — уровни, звёзды и звания остаются на устройстве.

## 4. Что лежит в папке

| Файл | Назначение |
|---|---|
| `index.html` | Вся игра (HTML + CSS + JS, без библиотек) |
| `manifest.webmanifest` | «Паспорт» приложения: имя, иконки, полноэкранный режим |
| `sw.js` | Service worker: офлайн-режим и кеш |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon-32.png` | Иконки |
| `serve.py` | Локальный сервер для запуска одной командой |
| `ДИЗАЙН.md` | Дизайн-документ: механики, 100 уровней, прогрессия, идеи |
| `уровни.csv` | Все 100 уровней таблицей |
| `lukoshko-site.zip` | Архив сайта для drag-and-drop деплоя |
| `deploy.sh`, `netlify.toml`, `_headers`, `vercel.json` | Публикация и заголовки |

Размер всей игры — **около 200 КБ**: грузится за секунду даже на слабом мобильном интернете.

## 5. Как менять уровни

1. Открыть `index.html`, найти массив `LEVELS` (ближе к концу скрипта).
2. Уровень — это объект:
```js
{n:34, w:3, t:'Больше пяти', r:[
  c('Лови цифры БОЛЬШЕ 5', ['6','7','8','9'], ['1','2','3','4','5'], 8,
    {letters:true, speed:1, rate:880})
]},
```
`n` — номер, `w` — мир (0–9), `t` — название, `r` — раунды, `c(подсказка, ловить, пропускать, сколько, настройки)`.
Типы: `catch`, `word`, `sort`, `mem`, `odd`, `seq`, `choice`.
3. Сохранить файл, обновить страницу. Если уже публиковали — поднять версию в `sw.js` и залить заново.

Баланс скорости: `speed` 0,7 — очень медленно (для 5 лет), 1,0 — обычно, 1,4+ — уже сложно.

## 6. Безопасность и приватность

- **Нет аккаунтов, регистрации, рекламы и внешних запросов.** Игра не отправляет никуда данные.
- **Прогресс** хранится в браузере (`localStorage`) на конкретном устройстве. Другой телефон — другой прогресс.
- **Нет ссылок наружу**, поэтому ребёнок не может «уйти» из игры в интернет.
- Сброс прогресса: настройки браузера → данные сайта → удалить для адреса игры.
- Хостинг по HTTPS (Netlify/GitHub Pages/Cloudflare) — обязательное условие для установки на телефон.
